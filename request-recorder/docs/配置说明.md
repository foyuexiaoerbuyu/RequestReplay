# RequestRecorder 配置说明

所有配置项前缀固定为 `request-recorder`，写在业务工程的 `application.yml` / `application.properties` 中。组件不自带默认数据库，`project-code` 与 `database.jdbc-url` 为必填项。

## 一、完整配置示例

```yaml
request-recorder:
  enabled: true                     # 总开关
  fail-fast: false                  # 配置非法时是否阻断启动
  project-code: order-service       # 必填
  project-name: 订单管理系统         # 可选，缺省回落 project-code
  description: 订单中心主服务        # 可选，写入 http_request_project.description
  max-body-size: 1048576            # 单请求/响应正文上限（字节）
  exclude-paths:                    # Ant 风格排除路径
    - /actuator/**
    - /favicon.ico
    - /error
    - /request-recorder/**
  record-static-resources: false    # 是否采集 js/css/图片
  skip-websocket: true
  skip-sse: true
  skip-file-download: true
  record-multipart: false
  auto-init-schema: false           # 表不存在时是否自动建表

  database:
    jdbc-url: jdbc:mysql://127.0.0.1:3306/request_recorder?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai
    username: recorder
    password: change-me
    driver-class-name: com.mysql.cj.jdbc.Driver
    pool-size: 3
    connection-timeout-ms: 3000
    validation-timeout-ms: 2000

  async:
    enabled: true
    queue-capacity: 5000
    workers: 2
    drop-when-full: true
    max-retries: 1
    retry-backoff-ms: 200
    shutdown-timeout-ms: 3000

  # 敏感信息掩码：注意 masking 必须与 async/database 同级，写在 async 下面不会生效
  # headers 置空 = 不掩码请求头，否则 authorization / cookie 落库为 ******，回放时原样发出必然 401
  masking:
    enabled: true
    headers:
      - authorization
      - cookie
      - set-cookie
      - x-api-key
      - proxy-authorization
    keys:
      - password
      - passwd
      - pwd
      - token
      - secret
      - access_token
      - refresh_token
      - id_card
      - idcard
      - mobile
      - phone
      - bank_card
      - cvv

  replay:
    skip-enabled: true
    header-name: X-Request-Replay
    header-value: "true"
```

完整示例

```

# ===== RequestRecorder 请求采集 =====
# 采集数据写入独立的 MySQL 库 request_recorder，与业务主库（人大金仓）/从库（MySQL jc6）分离，不影响业务数据。
# 关闭采集：把 enabled 改为 false 即可（无需删依赖）。
request-recorder:
  enabled: true
  # 项目编码：多项目共用一个采集库时用于数据隔离，也是回放时按项目筛选的依据
  project-code: my-project
  project-name: 示例业务系统
  description: RuoYi 3.x / Spring Boot 2.2.x / JDK8 接入示例
  # 首次启动自动建表（库需提前存在）；表已存在时无副作用
  auto-init-schema: true
  # 单请求/响应正文采集上限（字节），超出截断并打标记
  max-body-size: 262144
  # 不采集的路径；此处为覆盖默认值，务必保留 /error 与 /request-recorder/**
  exclude-paths:
    - /actuator/**
    - /favicon.ico
    - /error
    - /request-recorder/**
    - /druid/**
    - /swagger-resources/**
    - /v2/api-docs
    - /webjars/**
    - /captchaImage
    - /profile/**
  record-static-resources: false
  # 采集库连接（本机 MySQL）
  database:
    jdbc-url: jdbc:mysql://127.0.0.1:3306/request_recorder?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true
    driver-class-name: com.mysql.cj.jdbc.Driver
    username: root
    password: change-me
    pool-size: 3
  # 异步落库，避免采集影响业务接口响应
  async:
    enabled: true
    workers: 2
    queue-capacity: 500
  # 敏感信息掩码：注意 masking 必须与 async/database 同级，写在 async 下面不会生效
  # headers 置空 = 不掩码请求头，否则 authorization / cookie 落库为 ******，回放时原样发出必然 401
  masking:
    enabled: true
    headers: []
    keys: [password, passwd, pwd, id_card, idcard, bank_card, cvv]
```

## 二、配置项明细

### 1. 根级配置

| 配置项                       | 类型            | 默认值                                                           | 必填    | 说明                                                                        |
| ------------------------- | ------------- | ------------------------------------------------------------- | ----- | ------------------------------------------------------------------------- |
| `enabled`                 | boolean       | `true`                                                        | 否     | 总开关，`false` 时整套采集（含数据源、队列、Filter）都不装配                                     |
| `fail-fast`               | boolean       | `false`                                                       | 否     | 配置非法时是否抛异常阻断启动；`false` 表示打印错误并自动禁用采集                                      |
| `project-code`            | String        | 无                                                             | **是** | 项目唯一编码，多项目隔离依据，长度 ≤ 100                                                   |
| `project-name`            | String        | 回落 `project-code`                                             | 否     | 项目显示名，供 GUI 展示                                                            |
| `description`             | String        | 无                                                             | 否     | 项目描述，写入 `http_request_project.description`                                |
| `max-body-size`           | int           | `1048576`（1MB）                                                | 否     | 请求体与响应体采集上限，超出截断并标记 `*_truncated=1`；`0` 表示不截断（不推荐）                        |
| `exclude-paths`           | List\<String> | `/actuator/**`、`/favicon.ico`、`/error`、`/request-recorder/**` | 否     | Ant 风格通配（`*` 单段、`**` 多段、`?` 单字符）                                          |
| `record-static-resources` | boolean       | `false`                                                       | 否     | `false` 时 `.js/.css/.png/.jpg/.gif/.ico/.svg/.woff/.woff2/.ttf/.map` 直接跳过 |
| `skip-websocket`          | boolean       | `true`                                                        | 否     | 跳过 `Upgrade: websocket` 握手请求                                              |
| `skip-sse`                | boolean       | `true`                                                        | 否     | 跳过 `Accept: text/event-stream` 请求，且 SSE 响应体只留占位符                          |
| `skip-file-download`      | boolean       | `true`                                                        | 否     | 响应含 `Content-Disposition: attachment` 时不缓存正文                              |
| `record-multipart`        | boolean       | `false`                                                       | 否     | multipart 请求默认只记占位符（不解析文件内容）                                              |
| `auto-init-schema`        | boolean       | `false`                                                       | 否     | 启动时表不存在是否按内置 DDL 建表（H2/MySQL 均可，生产建议用 SQL 脚本建表）                           |

### 2. 独立数据库 `database.*`

| 配置项                     | 类型     | 默认值                        | 必填    | 说明                |
| ----------------------- | ------ | -------------------------- | ----- | ----------------- |
| `jdbc-url`              | String | 无                          | **是** | 采集库连接串，与业务数据源完全独立 |
| `username`              | String | 无                          | 否     | 采集库账号             |
| `password`              | String | 无                          | 否     | 采集库密码             |
| `driver-class-name`     | String | `com.mysql.cj.jdbc.Driver` | 否     | 使用 H2 等其它库时需显式指定  |
| `pool-size`             | int    | `3`                        | 否     | 独立连接池最大连接数，必须 ≥ 1 |
| `connection-timeout-ms` | long   | `3000`                     | 否     | 获取连接超时            |
| `validation-timeout-ms` | long   | `2000`                     | 否     | 连接有效性校验超时         |

说明：组件优先使用 HikariCP 自建独立连接池；若业务工程未引入 HikariCP，则自动回退到内置 JDBC 直连实现，保证「只加一个依赖也能跑」。无论哪种方式，都不使用业务工程的 `DataSource`、`JdbcTemplate`、`MyBatis` 或事务管理器。

### 3. 异步写入 `async.*`

| 配置项                   | 类型      | 默认值    | 必填  | 说明                                               |
| --------------------- | ------- | ------ | --- | ------------------------------------------------ |
| `enabled`             | boolean | `true` | 否   | `false` 时退化为同步写入（仅建议测试或低流量场景）                    |
| `queue-capacity`      | int     | `5000` | 否   | 有界队列容量，必须 ≥ 1；不会无限增长                             |
| `workers`             | int     | `2`    | 否   | 写入线程数，必须 ≥ 1                                     |
| `drop-when-full`      | boolean | `true` | 否   | 队列满策略：`true` 丢弃新记录（并计入 `dropped`），`false` 额外打印告警 |
| `max-retries`         | int     | `1`    | 否   | 写入失败重试次数（不含首次）                                   |
| `retry-backoff-ms`    | long    | `200`  | 否   | 重试间隔                                             |
| `shutdown-timeout-ms` | long    | `3000` | 否   | 停机排空队列的最长等待，超时丢弃剩余任务并计数                          |

### 4. 脱敏 `masking.*`

| 配置项       | 类型            | 默认值                                                                                                                             | 说明                      |
| --------- | ------------- | ------------------------------------------------------------------------------------------------------------------------------- | ----------------------- |
| `enabled` | boolean       | `true`                                                                                                                          | 关闭后敏感信息将原样入库，**不建议关闭**  |
| `headers` | List\<String> | `authorization`、`cookie`、`set-cookie`、`x-api-key`、`proxy-authorization`                                                         | 需要脱敏的请求/响应头，忽略大小写       |
| `keys`    | List\<String> | `password`、`passwd`、`pwd`、`token`、`secret`、`access_token`、`refresh_token`、`id_card`、`idcard`、`mobile`、`phone`、`bank_card`、`cvv` | JSON 字段与 Form 参数名，命中即脱敏 |

脱敏后的值统一替换为 `******`（响应头 `Set-Cookie` 同理）。

### 5. 防循环 `replay.*`

| 配置项            | 类型      | 默认值                | 说明                         |
| -------------- | ------- | ------------------ | -------------------------- |
| `skip-enabled` | boolean | `true`             | 是否跳过回放请求的采集                |
| `header-name`  | String  | `X-Request-Replay` | 回放标识头名                     |
| `header-value` | String  | `true`             | 回放标识头值，比较时忽略大小写；留空表示只要求头存在 |

判定逻辑：请求头名命中且值匹配（或 `header-value` 为空）时，跳过采集，业务请求本身照常执行。

## 三、配置校验规则

启动时按以下规则校验，错误信息写入日志（`request-recorder.fail-fast=true` 时直接抛异常）：

| 校验项                    | 规则          |
| ---------------------- | ----------- |
| `project-code`         | 非空且长度 ≤ 100 |
| `database.jdbc-url`    | 非空          |
| `database.pool-size`   | ≥ 1         |
| `async.queue-capacity` | ≥ 1         |
| `async.workers`        | ≥ 1         |
| `max-body-size`        | ≥ 0         |

校验不通过且未开启 `fail-fast` 时：日志打印 `RequestRecorder 已自动禁用采集，业务应用继续启动（原因：...）`，业务功能完全正常，只是不采集。

## 四、配置写法注意事项

1. **层级不要写错**：`workers` 属于 `async`，`jdbc-url` 属于 `database`，`: ` 后必须保留空格。
2. **properties 写法**同样支持（宽松绑定）：

```properties
request-recorder.project-code=order-service
request-recorder.database.jdbc-url=jdbc:mysql://127.0.0.1:3306/request_recorder?serverTimezone=Asia/Shanghai
request-recorder.database.username=recorder
request-recorder.database.password=change-me
request-recorder.async.workers=4
request-recorder.exclude-paths[0]=/actuator/**
```

3. **命令行覆盖**同样生效：`java -jar app.jar --request-recorder.enabled=false`。
4. **URL 中的 `&`**：YAML 中直接书写 `&` 是安全的；properties 文件同样无需转义。
5. **密码保护**：本文档示例密码为占位符，生产环境请使用配置中心或环境变量注入，勿提交明文密码。
